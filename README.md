# AI 기반 맞춤형 게임 추천 플랫폼

사용자의 게임 취향과 PC 사양을 바탕으로 자신에게 맞는 게임을 찾을 수 있도록 돕는 웹 서비스입니다.

React와 FastAPI를 활용해 프론트엔드와 백엔드를 분리하여 개발하고 있으며, 사용자 계정 기능을 기반으로 설문 및 AI 추천 기능을 확장할 계획입니다.

## 프로젝트 배경

게임을 선택할 때 장르, 플레이 스타일, 가격, PC 사양 등 다양한 조건을 확인해야 합니다.

사용자의 선호 조건을 설문으로 수집하고 게임 정보와 함께 분석하여, 게임 탐색과 선택에 필요한 정보를 한곳에서 제공하는 것을 목표로 합니다.

## 주요 기능 및 개발 방향

| 구분 | 내용 |
| --- | --- |
| 사용자 계정 | 회원가입, 로그인, 이메일 인증 및 비밀번호 재설정 |
| 취향 설문 | 선호 장르와 플레이 스타일 등 추천에 필요한 조건 수집 |
| 맞춤형 게임 추천 | 설문 결과와 게임 정보를 기반으로 추천 결과 제공 |
| 게임 검색 | 게임 목록 및 상세 정보 조회 |
| PC 사양 확인 | 사용자 PC 사양과 게임 요구 사양 비교 |
| 가격·리뷰 정보 | 게임 선택에 필요한 가격 정보와 리뷰 요약 제공 |
| 추천 피드백 | 추천 결과에 대한 사용자 평가 수집 |

> 현재 계정 관련 화면과 API를 중심으로 개발하고 있습니다. 설문, 게임 추천, 사양 비교 등의 기능은 단계적으로 구현할 예정입니다.

## 기술 스택

| 영역 | 기술 | 용도 |
| --- | --- | --- |
| 프론트엔드 | React, JavaScript | 사용자 화면 및 상태 관리 |
| 화면 이동 | React Router | 페이지 간 이동 |
| API 통신 | Axios | 프론트엔드와 백엔드 간 요청·응답 |
| 백엔드 | FastAPI, Python | REST API 및 데이터 처리 |
| 데이터베이스 | PostgreSQL | 사용자 및 서비스 데이터 저장 |
| DB 연동 | SQLAlchemy | 데이터베이스 접근 |
| 버전 관리 | Git, GitHub | 소스 코드 및 변경 이력 관리 |

## 서비스 이용 흐름

1. 사용자가 회원가입 후 로그인합니다.
2. 선호 장르와 플레이 스타일에 대한 설문을 작성합니다.
3. 서버가 설문 결과를 저장하고 추천에 사용할 게임 후보를 조회합니다.
4. 추천 로직이 사용자 조건과 게임 정보를 비교합니다.
5. 사용자가 추천 결과와 게임 상세 정보를 확인합니다.
6. 추천에 대한 피드백을 남깁니다.

※ 위 흐름은 목표 서비스 설계이며, 개발 진행에 따라 변경될 수 있습니다.

- `game_pj/backend/`: FastAPI 기반 API 서버
